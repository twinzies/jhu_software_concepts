    Project Description

    This project uses a micro web framework, Flask to develop a web application. The web application is a basic professional portfolio.

    Project Link

    View this project on GitHub

    Key Takeaways

    The key learnings for me were around:

    1. Seeing how the factory method design is used in a Flask application. The app/__init__.py contains the "factory" with the factory method (create_app). And, run.py provides the (client) code that uses the factory.
    2. How to structure a Flask application with routes, templates, and static assets (as demonstrated by this project) and use a blueprint to group routes.
    3. Using Jinja template inheritance to share a consistent page layout (though there is some confusion around this concept for me that I hope to sort this out in office hours or via email).
    4. Styling reusable page components with CSS.
